# Versi lama

`powershell-watchdog/` adalah WatchCat generasi pertama: satu skrip PowerShell yang berjalan di latar belakang lewat tugas terjadwal, tanpa Node.js. Fiturnya terbatas (bloatware, autostart, leak, CPU, RAM; notifikasi toast) dan tidak lagi dikembangkan aktif. Lihat README di dalamnya.

Untuk antarmuka penuh, grafik, dan Telegram gunakan TUI di akar repositori.
